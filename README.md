# Slow Living with Princess — ม็อดแปลไทย

ม็อดแปลภาษาไทยแบบไม่เป็นทางการสำหรับเกม **Slow living with Princess** เวอร์ชัน Windows บน Steam โดยใช้ช่องภาษาอังกฤษของเกม

> โครงการนี้เป็นงานแฟนเมด ไม่ได้เกี่ยวข้องหรือได้รับการรับรองจากผู้พัฒนา ผู้จัดจำหน่าย หรือเจ้าของลิขสิทธิ์เกม ผู้ใช้ต้องมีเกมฉบับถูกลิขสิทธิ์จึงจะติดตั้งได้ และรีโพนี้ไม่มีไฟล์เกมต้นฉบับ

## สถานะการแปล

- บทสนทนา 5,888 ชุด
- ข้อความบอลลูนและข้อความเหนือหัวตัวละคร 1,035 รายการ
- UI ฐานข้อมูล ไอเทม เควส สกิล และข้อความระบบ 3,854 รายการ
- ข้อความสำรองของ RPG Maker 330 รายการ
- Achievement ของ Steam 26 รายการ
- หน้าข้อผิดพลาด 2 รายการ
- ใช้ฟอนต์ Noto Sans Thai เพื่อลดปัญหาสระและวรรณยุกต์ซ้อนกัน

คำแปลเริ่มต้นบางส่วนใช้ AI ช่วยและมีการตรวจแก้จากการเล่นจริงแล้ว แต่ยังอาจพบประโยคที่ไม่เป็นธรรมชาติ คำล้นกรอบ หรือบริบทคลาดเคลื่อนได้ หากพบสามารถเปิด Issue พร้อมภาพและข้อความต้นฉบับได้

ข้อความที่อยู่ในรูปภาพและเครดิตยังไม่ได้แปล

## สิ่งที่ต้องมี

- เกม **Slow living with Princess** เวอร์ชัน Windows จาก Steam
- ปิดเกมก่อนติดตั้งหรือถอนการติดตั้ง

ไม่ต้องติดตั้ง Node.js ไม่ต้องเปิด PowerShell ไม่ต้องมี OpenAI API key และม็อดไม่เชื่อมต่อบริการ AI

## การติดตั้ง

1. ดาวน์โหลดไฟล์ `SlowLivingwithPrincess-Thai-Mod-v0.3.0.zip` จากหน้า Releases
2. ใน Steam คลิกขวาที่เกม แล้วเลือก **จัดการ (Manage) → เปิดหาไฟล์ภายในเครื่อง (Browse local files)**
3. ปิดเกม แล้วแตกไฟล์ทุกอย่างใน ZIP ลงในโฟลเดอร์ที่มี `Game.exe`
4. เมื่อ Windows ถาม ให้เลือกแทนที่ไฟล์ `index.html`
5. เปิดเกมตามปกติและเลือกภาษา **English**

หลังแตกไฟล์แล้ว โครงสร้างสำคัญควรเป็นแบบนี้:

```text
Slow living with Princess\
├─ Game.exe
├─ index.html
└─ thai_mod\
   ├─ bootstrap.js
   ├─ patch-manifest.json
   └─ NotoSansThai-Regular.ttf
```

ตอนเปิดเกมครั้งแรก ม็อดจะตรวจเวอร์ชันและใส่คำแปลให้เองโดยใช้ระบบที่มากับตัวเกม หากไฟล์เกมไม่ตรงกับเวอร์ชันที่รองรับ เกมจะแสดงหน้าข้อผิดพลาดและจะไม่แพตช์ไฟล์นั้น

## การถอนการติดตั้ง

1. ปิดเกม
2. ใน Steam คลิกขวาที่เกม แล้วเลือก **คุณสมบัติ (Properties) → ไฟล์ที่ติดตั้ง (Installed Files)**
3. กด **ตรวจสอบความสมบูรณ์ของไฟล์เกม (Verify integrity of game files)**

Steam จะคืนไฟล์เกมและ `index.html` เดิม ทำให้ม็อดหยุดทำงาน โฟลเดอร์ `thai_mod` และไฟล์ `fonts/NotoSansThai-Regular.ttf` เป็นไฟล์เพิ่มใหม่ซึ่ง Steam อาจไม่ลบ แต่สามารถลบเองได้อย่างปลอดภัยหลังตรวจไฟล์เสร็จ

## การอัปเดตม็อด

1. ใช้ Steam ตรวจสอบความสมบูรณ์ของไฟล์เกมเพื่อคืนไฟล์เดิม
2. ดาวน์โหลด ZIP เวอร์ชันใหม่
3. แตกทับลงในโฟลเดอร์เกมเหมือนขั้นตอนติดตั้ง

## แก้ปัญหาเบื้องต้น

### แจ้งว่าไฟล์เกมไม่ตรงกับเวอร์ชันที่รองรับ

ม็อดรองรับเฉพาะไฟล์เกมเวอร์ชันที่ใช้สร้างแพตช์ หากติดตั้งม็อดอื่นอยู่ ให้คืนไฟล์เดิมก่อน หรือใช้ Steam ตรวจสอบความสมบูรณ์ของไฟล์เกม แล้วแตก ZIP ม็อดทับใหม่

### เกมยังแสดงภาษาอังกฤษ

ตรวจว่าเลือกภาษา English ในเกม และตรวจว่า `index.html` กับโฟลเดอร์ `thai_mod` อยู่ข้าง `Game.exe` หาก Steam อัปเดตหรือซ่อมไฟล์หลังติดตั้ง ต้องแตก ZIP ม็อดทับใหม่

### เปิดเกมแล้วขึ้นหน้าติดตั้งม็อดไม่สำเร็จ

มักเกิดจากไฟล์เกมเป็นคนละเวอร์ชันหรือมีม็อดอื่นแก้ไขไฟล์เดียวกัน ให้ใช้ Steam ตรวจสอบความสมบูรณ์ของไฟล์เกม แล้วแตก ZIP ม็อดทับใหม่

## การรายงานคำแปลผิด

กรุณาเปิด Issue โดยแนบข้อมูลเท่าที่หาได้:

- ภาพหน้าจอ
- ข้อความไทยที่พบและข้อความที่ควรเป็น
- ชื่อตัวละครหรือชื่อเควส
- จุดที่พบ เช่น วันในเกม สถานที่ หรือเหตุการณ์

มาตรฐานชื่อหลักที่ใช้ตอนนี้ ได้แก่ **ริท**, **รูตี้**, **เรด**, **ทันตะ**, **บิ๊กฮอว์ก**, **โซลตัน** และ **หินกลับบ้าน**
