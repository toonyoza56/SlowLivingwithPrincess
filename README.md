# Slow Living with Princess — ม็อดแปลไทย

ม็อดแปลภาษาไทยแบบไม่เป็นทางการสำหรับเกม **Slow living with Princess** เวอร์ชัน Windows บน Steam โดยใช้ช่องภาษาอังกฤษของเกม

> โครงการนี้เป็นงานแฟนเมด ไม่ได้เกี่ยวข้องหรือได้รับการรับรองจากผู้พัฒนา ผู้จัดจำหน่าย หรือเจ้าของลิขสิทธิ์เกม ผู้ใช้ต้องมีเกมฉบับถูกลิขสิทธิ์จึงจะติดตั้งได้ และรีโพนี้ไม่มีไฟล์เกมต้นฉบับ

## สถานะการแปล

- บทสนทนา 5,888 ชุด
- ข้อความบอลลูนและข้อความเหนือหัวตัวละคร 1,035 รายการ
- UI ฐานข้อมูล ไอเทม เควส สกิล และข้อความระบบ 3,854 รายการ
- ข้อความสำรองของ RPG Maker 330 รายการ
- Achievement ของ Steam 26 รายการ
- หน้าข้อผิดพลาด 2 รายการ
- ใช้ฟอนต์ Noto Sans Thai เพื่อลดปัญหาสระและวรรณยุกต์ซ้อนกัน

คำแปลเริ่มต้นบางส่วนใช้ AI ช่วยและมีการตรวจแก้จากการเล่นจริงแล้ว แต่ยังอาจพบประโยคที่ไม่เป็นธรรมชาติ คำล้นกรอบ หรือบริบทคลาดเคลื่อนได้ หากพบสามารถเปิด Issue พร้อมภาพและข้อความต้นฉบับได้

ข้อความที่อยู่ในรูปภาพและเครดิตยังไม่ได้แปล

## สิ่งที่ต้องมี

- เกม **Slow living with Princess** เวอร์ชัน Windows จาก Steam
- [Node.js](https://nodejs.org/) เวอร์ชัน 18 ขึ้นไป
- ปิดเกมก่อนติดตั้งหรือถอนการติดตั้ง

ผู้เล่นไม่ต้องมี OpenAI API key และตัวติดตั้งไม่เชื่อมต่อบริการ AI

## การติดตั้ง

1. ดาวน์โหลด ZIP จากหน้า Releases แล้วแตกไฟล์ออกมาก่อน ห้ามเรียกสคริปต์จากในไฟล์ ZIP
2. ปิดเกม
3. เปิด PowerShell ในโฟลเดอร์ม็อด
4. เรียกคำสั่งต่อไปนี้ โดยเปลี่ยนพาธให้ตรงกับตำแหน่งเกมของคุณ

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -GamePath "D:\SteamLibrary\steamapps\common\Slow living with Princess"
```

หากวางโฟลเดอร์ม็อดไว้ภายในโฟลเดอร์เกมโดยตรง สามารถเรียกได้โดยไม่ต้องระบุ `-GamePath`

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

เมื่อติดตั้งสำเร็จ ให้เปิดเกมและเลือกภาษา **English** เพราะม็อดแทนที่ช่องภาษาอังกฤษ

ตัวติดตั้งจะตรวจสอบเวอร์ชันไฟล์เกมก่อนแก้ไข และสร้างไฟล์สำรองไว้ใน `state/backups` ภายในโฟลเดอร์ม็อดโดยอัตโนมัติ

## การถอนการติดตั้ง

ปิดเกม แล้วเปิด PowerShell ในโฟลเดอร์ม็อดเดิม จากนั้นเรียก

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1 -GamePath "D:\SteamLibrary\steamapps\common\Slow living with Princess"
```

หากโฟลเดอร์ม็อดอยู่ภายในโฟลเดอร์เกมโดยตรง ไม่จำเป็นต้องระบุ `-GamePath`

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

การถอนจะคืนไฟล์จากชุดสำรองที่ตัวติดตั้งสร้างไว้ หากไฟล์เกมถูกแก้ไขหลังติดตั้ง โปรแกรมจะหยุดเพื่อป้องกันข้อมูลสูญหาย ควรสำรองไฟล์นั้นก่อน แล้วจึงใช้ตัวเลือก `-Force` เฉพาะเมื่อเข้าใจผลกระทบ

## การอัปเดตม็อด

1. ถอนม็อดเวอร์ชันเดิมด้วย `uninstall.ps1`
2. ดาวน์โหลดและแตกไฟล์ม็อดเวอร์ชันใหม่
3. ติดตั้งอีกครั้งด้วย `install.ps1`

ไม่ควรลบโฟลเดอร์ม็อดเดิมก่อนถอน เพราะไฟล์สำรองอยู่ใน `state/backups`

## แก้ปัญหาเบื้องต้น

### แจ้งว่าไฟล์เกมไม่ตรงกับเวอร์ชันที่รองรับ

ม็อดรองรับเฉพาะไฟล์เกมเวอร์ชันที่ใช้สร้างแพตช์ หากติดตั้งม็อดอื่นอยู่ ให้คืนไฟล์เดิมก่อน หรือใช้ Steam ตรวจสอบความสมบูรณ์ของไฟล์เกม แล้วลองติดตั้งใหม่

### PowerShell แจ้งว่าไม่พบ Node.js

ติดตั้ง Node.js 18 ขึ้นไป ปิดแล้วเปิด PowerShell ใหม่ จากนั้นตรวจด้วย

```powershell
node --version
```

### เกมยังแสดงภาษาอังกฤษ

ตรวจว่าเลือกภาษา English ในเกม และดูว่าการติดตั้งจบด้วยข้อความสำเร็จ หาก Steam อัปเดตหรือซ่อมไฟล์หลังติดตั้ง ต้องติดตั้งม็อดใหม่

## การรายงานคำแปลผิด

กรุณาเปิด Issue โดยแนบข้อมูลเท่าที่หาได้:

- ภาพหน้าจอ
- ข้อความไทยที่พบและข้อความที่ควรเป็น
- ชื่อตัวละครหรือชื่อเควส
- จุดที่พบ เช่น วันในเกม สถานที่ หรือเหตุการณ์

มาตรฐานชื่อหลักที่ใช้ตอนนี้ ได้แก่ **ริท**, **รูตี้**, **เรด**, **ทันตะ**, **บิ๊กฮอว์ก**, **โซลตัน** และ **หินกลับบ้าน**
